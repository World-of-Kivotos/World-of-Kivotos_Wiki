想让别人在你的地里做点什么,流程是三步: 建一个组、给这个组勾权限、把人加进这个组。不能给某个人单独配权限 —— 权限只挂在组上。一个人同时只能属于一个组。

## 两个自带的组

每块新领地建好时会自动带上两个组,直接用就行,不用自己配。

:::table
| 组名 | 能干什么 |
| --- | --- |
| Co-Owner | 全部权限, 包括改权限、加人踢人、改领地大小、删掉这块地 |
| Visitor | 睡床、开门、开栅栏门、开活板门、按按钮拉拉杆、踩压力板、用末影箱、用附魔台、转展示框里的物品、走传送门、和村民交易 —— 共 11 项 |
:::

> Co-Owner 是真的什么都能做, 包括把这块地删掉。除非对方是你完全信得过的共同房主, 否则别用它。

## 加人: 最快的做法

1. 站在自己领地里输入 /flan menu。
2. 点第 3 格(书与笔)进入权限组列表。
3. 左键你想用的那个组的纸片 —— 记住左键是管人, 右键是管权限。
4. 点第 3 格(铁砧)打开输入框, 填对方的玩家名, 然后点右边的书提交。
5. 回到名单里能看到对方的头像, 就算加成功了。

> 也可以用命令一次加一批: /flan group players add <组名> <玩家1> <玩家2>。命令里的组名不能带空格。

## 新建一个自己的组

1. 在权限组列表里点第 3 格(铁砧),输入新组名,点书提交。
2. 回到列表,右键刚建的那张纸,进入这个组的权限编辑。
3. 找到要开的权限项,点一下推进状态,直到悬停显示绿色的"启用"。
4. 返回列表,左键这张纸,把人加进去。

- 权限项有三态: 默认 / 禁止 / 启用, 点击循环推进。选"默认"表示这条不由组决定, 回落到整块地的设置。
- 组权限菜单里看不到全局类权限(PvP、爆炸、刷怪等) —— 那些只能整块地统一设。
- 组名可以带空格, 但带空格的组名没法用命令操作, 只能在菜单里管。建议用纯英文不带空格的名字。

## 踢人和删组

:::table{mono="1"}
| 要做的事 | 怎么做 |
| --- | --- |
| 把某人踢出领地 | 进组成员列表 -> 点第 4 格红石块开启删除模式 -> 点那个人的头 |
| 用命令踢人 | /flan group players remove <组名> <玩家> |
| 删掉整个组 | 在权限组列表开启删除模式 -> 点那张纸。组里的人会一起被踢出去 |
| 用命令删组 | /flan group remove <组名> |
:::

> 命令踢人时填的组名其实只影响补全 —— 不管对方在哪个组, 都会被移出领地。

## 常见需求怎么配

:::table
| 你想让对方 | 开这几项就够 |
| --- | --- |
| 帮忙盖房子 | 破坏、放置 |
| 来住但不许乱翻 | 用自带的 Visitor 组 |
| 帮你打理箱子 | 开启容器 |
| 管你的农场 | 破坏、放置、互动方块、使用桶 |
| 照顾你的动物 | 互动动物、开启容器 |
| 能传送到你家 | 传送 |
| 当共同房主 | 用自带的 Co-Owner 组 |
:::

> 临时帮忙的人事后记得移出去 —— 权限不会自己过期。要更精细的控制, 就在领地里划一块子领地, 只在那一小块里放权限。

## 个人默认模板: 一次配好, 以后每块地都带上

如果你经常圈地,每次重新配组很烦。用 /flan personalGroups 可以配一套属于你自己的模板,以后新圈的每一块地都自动带上这套组和权限。

- 这个命令不需要站在领地里, 随时随地能开。
- 界面用法和领地里的权限组列表完全一样。
- 只影响以后新建的地, 已经圈好的领地不受影响。

> 重要: 一旦你配了个人模板, 新领地就不再自动生成 Co-Owner 和 Visitor 了 —— 是替换关系不是叠加。如果你还想要这两个组, 得在模板里自己建同名的。

## 关于加人的两个坑

- 如果服务器的名字缓存里查不到你输入的玩家名, 界面会播成功音效但其实谁都没加进去。加完务必退出去重开菜单核对一眼名单。
- 对方如果已经在别的组里, 普通的加人操作不会改动他。要强制换组得用命令加 overwrite: /flan group players add <组名> <玩家> overwrite。
- 领地主人本人加不进任何组 —— 你本来就绕过一切权限, 不需要。
