Flan 没有自己的界面材质 —— 它开的就是原版箱子,往格子里塞带名字的物品当按钮,你点哪一格服务端就执行哪段逻辑。所以原版客户端就能用全部功能,不用装任何东西。菜单里的物品也拿不走,怎么点都不会掉进背包。下面所有槽位号都从左上角的 0 开始,逐行从左往右数。

## 领地菜单: 一切的入口

站在自己的领地里输入 /flan menu 就会打开它。如果你切到了子领地模式,打开的是脚下子领地的菜单。

- 没权限的按钮不会消失, 而是加一行深红的"没有权限"。点下去只响一声拒绝音, 不跳转。
- 灰色玻璃板是填充用的, 点了没有任何反应。
- 在子领地菜单里, 药水、删除、六种白名单判的都是父领地的权限, 不是子领地自己的。

:::menu{title="领地菜单 / 子领地菜单" rows="3" openedBy="/flan menu(必须站在领地内)"}
| 槽位 | 物品 | 点击效果 |
| --- | --- | --- |
| 0 | TNT 关闭 | 关掉界面 |
| 2 | 信标 全域权限 | 设置这块地对所有人的默认权限 |
| 3 | 书与笔 权限组 | 建组、加人、给组配权限 |
| 4 | 药水 附加效果 | 给领地内的人挂持续药水效果 |
| 5 | 告示牌 进出文字 | 编辑别人进出这块地时弹的标题 |
| 6 | 僵尸头 假人 | 允许指定的机器假人在这里干活 |
| 8 | 屏障 删除领地 | 弹出确认框, 确认后删掉这块地 |
| 11 | 水瓶 物品白名单 | 列进去的物品谁都能在这块地用 |
| 12 | 钻石镐 可破坏方块 | 列进去的方块谁都能挖 |
| 13 | 钻石锹 可放置方块 | 列进去的方块谁都能放 |
| 14 | 红旗 可使用方块 | 列进去的方块谁都能右键 |
| 15 | 钻石剑 可攻击实体 | 列进去的生物谁都能打 |
| 20 | 剪刀 可交互实体 | 列进去的生物谁都能右键 |
:::

> 菜单顶上第一格在主菜单是"关闭", 在其它所有菜单里都是"返回"。图标都是 TNT, 别点错。

## 权限编辑菜单

从主菜单第 2 格进来是整块地的默认权限;从权限组列表里右键某个组进来则是那个组的权限。两者界面完全一样,区别只在改的是谁。

每格是一项权限,图标就是那项权限自己的图标(破坏是钻石镐、开容器是箱子、爆炸是 TNT)。当前是开是关不看图标 —— 要把鼠标悬上去看最后一行说明。

- 全域权限菜单列出全部权限项, 共 3 页; 组权限菜单会剔除全局类权限, 只有 2 页。
- 全局类权限(飞行、刷怪、传送这些)只能整块地统一设, 不能按组区分, 所以组菜单里根本看不到它们。
- 被服主锁死的权限项会带一行深红的"不可编辑", 点了只响拒绝音。

:::menu{title="全域权限 / 某个组的权限" rows="6" openedBy="领地菜单第 2 格; 或权限组列表里右键一个组"}
| 槽位 | 物品 | 点击效果 |
| --- | --- | --- |
| 0 | 返回 | 回领地菜单或权限组列表 |
| 10-16,19-25,28-34,37-43 | 权限项 | 点一下推进一档状态 |
| 47 | 上一页 | 不在第一页时才出现 |
| 51 | 下一页 | 还有下一页时才出现 |
:::

## 权限三态怎么循环

点一下推进一档,循环往复,没有反向。左键右键 shift 点击效果完全一样,只有双击会被忽略。

- 子领地的权限、权限组的权限、个人组的权限都是三态: 默认 -> 禁用 -> 启用 -> 默认。
- 顶层领地的全域权限只有两态: 启用 <-> 未设置。因为顶层没有上一层可以继承。
- 组权限设成"默认", 意思是这条不由组说了算, 回落到整块地的全域设置。
- 注意"默认"和"禁用"都显示红色, 只能靠文字区分。

:::table
| 状态 | 悬停显示 | 含义 |
| --- | --- | --- |
| 启用 | 绿色的"启用" | 明确允许 |
| 禁用 | 红色的"禁用" | 明确禁止 |
| 默认 | 红色的"默认" | 没设置, 跟随上一层 |
:::

> 推不动的三种情况: 服主把这条锁死了、你自己没有修改权限的资格、或者你在组菜单里想改一条全局权限。

## 列表类菜单: 五个菜单共用一套骨架

权限组列表、组成员列表、药水效果、六种交互白名单、假人名单,这五类菜单长得一模一样:左上角返回,第 3 格铁砧是新增,第 4 格红石块是删除模式开关,中间 28 格是条目,底部两个箭头翻页。

删除条目的方式是先点红石块打开删除模式,再点要删的那一格。删除模式不会关闭界面,再点一次就关掉。

:::table{caption="新增时铁砧输入框该填什么" mono="2"}
| 从哪个菜单进 | 输入内容 | 例子 |
| --- | --- | --- |
| 权限组列表 | 新组名 | friends |
| 组成员列表 | 玩家名 | Steve |
| 药水效果 | 效果id;等级, 用英文分号 | minecraft:regeneration;1 |
| 交互白名单 | 注册 id, 或 # 开头的标签 | #minecraft:doors |
| 假人名单 | 玩家名(不是 UUID) | FakePlayerName |
:::

:::menu{title="列表类菜单通用骨架" rows="6" openedBy="领地菜单第 3/4/6/11/12/13/14/15/20 格"}
| 槽位 | 物品 | 点击效果 |
| --- | --- | --- |
| 0 | 返回 | 回上一级菜单 |
| 3 | 新增 | 打开铁砧输入框, 输入后点书提交 |
| 4 | 删除模式 | 就地开关删除模式, 不跳转 |
| 10-16,19-25,28-34,37-43 | 条目 | 一页 28 项, 按顺序排布 |
| 47 | 上一页 | 不在第一页时才出现 |
| 51 | 下一页 | 还有下一页时才出现 |
:::

> 铁砧界面里点右边的书是提交, 点左边的纸是取消。一个字都不输入直接点书没有反应。

## 权限组列表: 唯一左右键有区别的地方

组列表里每张纸代表一个组。这是整套菜单里唯一一处左键和右键干不同事的地方,记住这条能省很多来回。

- 左键一张组名纸 = 管人。进去看谁在这个组里, 加人删人。
- 右键一张组名纸 = 管权限。进去配这个组能干什么。
- 开着删除模式时左右键都一样, 都是删掉这个组。

> 删组会把组里所有人一起踢出领地成员, 不是只解散组。

## 进出提示语编辑器

别人走进或走出你的领地时,屏幕中央可以弹一行标题。这个只有一行九格,很小。

- 左键打开铁砧输入框, 填纯文本就行, 最省事。
- 右键会关掉界面并在聊天栏丢一条可点击的消息, 点它把命令填进输入框, 你自己在后面接 JSON 文本 —— 想要彩色或可点击的标题才需要这样。
- 把内容填成 $empty 就是清空这条提示语。

:::menu{title="领地信息 / 子领地信息" rows="1" openedBy="领地菜单第 5 格"}
| 槽位 | 物品 | 点击效果 |
| --- | --- | --- |
| 0 | 返回 | 回领地菜单 |
| 2 | 进入 主标题 | 左键输入纯文本; 右键改用命令填 JSON |
| 3 | 进入 副标题 | 同上 |
| 4 | 离开 主标题 | 同上 |
| 5 | 离开 副标题 | 同上 |
:::

## 删除确认框

只在删除领地时出现,一行九格,绿羊毛确认、红羊毛取消。

:::menu{title="确认" rows="1" openedBy="领地菜单第 8 格(删除领地)"}
| 槽位 | 物品 | 点击效果 |
| --- | --- | --- |
| 3 | 绿羊毛 是 | 真的删掉这块领地 |
| 5 | 红羊毛 否 | 取消, 回领地菜单 |
:::

## 个人默认分组

这个不在领地菜单里,要用 /flan personalGroups 打开,而且不用站在领地里。它是一份属于你个人的模板: 配好之后,你以后新圈的每一块地都自动带上这套分组。

界面和列表类菜单一样。点一个组进去就是编辑这个组的权限。

> 一旦你配了个人分组模板, 新领地就不再自动生成 Co-Owner 和 Visitor 这两个默认组了 —— 是替换关系, 不是叠加。它也只影响以后新建的地, 已有的领地不受影响。

## 音效在告诉你什么

:::table
| 听到的声音 | 含义 |
| --- | --- |
| 按钮咔哒声 | 正常导航: 进菜单、返回、翻页、切换删除模式 |
| 村民否定声 | 失败: 没权限、取消输入、权限推不动 |
| 音符盒叮的一声 | 权限成功推进了一档 |
| 铁砧使用声 | 铁砧输入框提交了 |
| 蝙蝠死亡声 | 删除模式下删掉了一条 |
| 铁砧放置声 | 领地被删除了 |
:::

> 铁砧提交声和删除声是无条件播放的 —— 听到不等于真的改成功了。改完最好退出去重开菜单确认一眼。

## 几个已知的界面怪毛病

这些是从源码里读出来的实际行为,不是猜的。知道了能少踩坑。

:::table
| 现象 | 实际情况 | 绕过办法 |
| --- | --- | --- |
| 删掉"可攻击实体"或"可交互实体"里的条目, 重开菜单还在 | 界面清空了格子也放了音效, 但底层名单根本没改 | 改用命令: /flan ignoreList remove entity_attack <条目> |
| 药水效果菜单永远显示没有权限 | 默认配置把编辑药水这项在全服锁成了禁止, 包括领地主人在内谁都进不去 | 需要服主改配置, 或者把这块地设成管理员领地 |
| 加成员时听到成功音效, 但人没进来 | 服务器的名字缓存里查不到这个玩家时, 代码会误判成功 | 确认对方进过服、名字拼写正确, 再重开菜单核对名单 |
| 按钮显示"没有权限"却点得进去(或反过来) | 几个按钮的灰化判断和点击判断查的不是同一项权限 | 以实际点击结果为准, 别信那行红字 |
| 新建权限组听到提交音效但组没出现 | 没有修改权限资格时建组会静默失败, 音效照样播 | 重开菜单确认组是否真的建出来了 |
:::
